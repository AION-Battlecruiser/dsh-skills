# 핸드오프 — <작업명> <NN>세대 → <NN+1>세대

파일: `<handoff_dir>\<작업명>_<NN>.md` (handoff_dir = 교대 알림·worker_status 출력, 기본 `~/.dsh/worker-orchestrator/handoff`) (세대마다 새 파일, 덮어쓰지 않음). 다음 근무자는 이 파일 1개만 읽는다.

## 목표
<사용자 원문 1줄>

## 지금까지 (끝난 것 — 검증 PASS 또는 GATE 예외만. 받은 것에 이어 누적, 압축)
- <배치·조각 범위 1줄> → <결과 파일·폴더 경로>  (예: b01~b07 완료·PASS → <작업 폴더>\...\out\)
- 미검증·FAIL·UNKNOWN은 여기 말고 '다음 할 일'에 (검증 또는 재작업으로)

## 다음 할 일 (여기부터 시작, 순서대로)
1. <할 일>

## 주의·조심할 것
- <함정, 하지 말 것, 이미 막힌 길과 그 이유>

## 발견·확정 사실
- <사실> (근거: <경로>) — 추정이면 '추정' 표기

## 중요
- <사용자 지시·판단 기준·약속>

## 사용자 답 대기
- <없으면 '없음'>

## 교대 기록 (기준 다시 맞추는 데 씀)
- 교대 때 창: <[교대 알림]에 적힌 숫자, 알림 없이 교대면 '모름'> · 같은 지적 2회 정정 실패: <있음/없음> · 이 세대 사용자 지적 수: <n> · 교대 사유: <400k / 2회 정정 실패 / 주제 변경 / 사용자 '교대'>

---
쓰는 규칙: '지금까지'는 지우지 않고 누적하되 범위로 압축한다. 다음 할 일·주의·사실·중요는 아직 유효한 것만 옮기고 해결된 건 지운다. 결과 본문은 붙이지 말고 경로만. 대화 복사 금지. 받는 코디는 '지금까지'에 적힌 조각만 끝난 것으로 본다.

마지막에 아래 1줄을 코드블록으로 출력하고 종료:
```
워커오케스트레이션: <handoff_dir>\<작업명>_<NN>.md 읽고 '다음 할 일'부터 바로 이어서 작업 시작
```
